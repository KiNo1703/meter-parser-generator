# ⚡ Генератор команд для счетчиков электроэнергии



## 📋 ОПИСАНИЕ

Веб-инструмент для генерации HEX-команд планировщика DLMS (F002) и парсинга ответов (F001) для различных моделей счетчиков электроэнергии.

Поддерживаются счетчики:
- **Энергомера** (CE208, CE207, CE307, CE308)
- **Меркурий** (150, 230, 238)
- **Нева** (414, 413)

## 🚀 БЫСТРЫЙ СТАРТ

### 1️⃣ Запуск
Просто откройте `index.html` в любом современном браузере!

### 2️⃣ Выбор счетчика
**Новое удобство: видимый список моделей + поиск!**
- Выберите **производителя** из выпадающего списка
- Внизу появляется **список всех моделей** этого производителя (5 видимых одновременно)
- **Опционально**: введите текст в поле поиска, чтобы отфильтровать модели
  - Поиск работает по названию, ID или номеру журнала
  - Список обновляется в реальном времени
- Нажмите на нужную модель в списке → **автоматическое переключение!**

### 3️⃣ Настройка задачи
- **Задача №** - номер задачи планировщика (0-255)
- **Период** - интервал опроса в секундах (автоматический перевод в минуты/часы)
- **Задержка** - задержка перед первым выполнением

### 4️⃣ Выбор объектов
- Отметьте нужные объекты в группах (A+, A-, R+, R-)
- Используйте **быстрые пресеты** для частых комбинаций
- Нажмите **"СГЕНЕРИРОВАТЬ КОМАНДУ"**

### 5️⃣ Парсер ответов
- Переключитесь на вкладку **"Парсер ответов"**
- Вставьте HEX-ответ (F001) от счетчика
- Нажмите **"Анализ"** - объекты автоматически отметятся галочками
- Можно редактировать и генерировать новую команду

## � ИСПОЛЬЗОВАНИЕ ПОИСКА И АВТОКЭША

### 🔎 Поиск по моделям
**Одновременное отображение всех моделей + возможность фильтрации**:

1. **Видимый список**: После выбора производителя показывается 5 моделей одновременно
2. **Прокрутка**: Если моделей больше 5, используйте прокрутку списка
3. **Фильтрация при вводе**: 
   - Введите текст в поле "Поиск или выбор модели..."
   - Список автоматически показывает только совпадающие модели
   - Поиск работает по:
     - **Названию**: `207`, `308` → найдет энергомеру-207
     - **ID модели**: `mercury`, `neva` → найдет модели производителя
     - **Журналу**: `0x1E`, `1E` → найдет модели с этим журналом
4. **Выбор**: Нажмите на модель в списке → **автоматическое переключение!**
5. **Очистка поиска**: Удалите текст → вернется полный список моделей

### 📦 Автосохранение и восстановление
**Приложение запоминает вашу работу**:
- ✅ При выборе модели → сохраняется в браузер
- ✅ При открытии страницы → автоматически загружается последняя модель
- ✅ Сохраняется как производитель, так и конкретная модель
- ℹ️ Данные хранятся локально в браузере (localStorage)

**Пример**:
1. Вы выбрали "Энергомера 308" → автоматически сохранилось
2. Закрыли вкладку браузера
3. Открыли приложение снова → "Энергомера 308" и производитель "Энергомера" уже выбраны!
