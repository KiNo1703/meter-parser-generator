🔧 ДИАГНОСТИКА ИНТЕГРАЦИИ МАППИНГА
===================================

## НОВОЕ РЕШЕНИЕ: ВЫБОР МОДЕЛИ ВРУЧНУЮ

Вместо автоматического определения модели, теперь можно выбрать модель из dropdown'а (как в генераторе).

---

## ШАГ 1: ЗАПУСК И ВЫБОР МОДЕЛИ

1. Откройте файл: 📄 суточные сподэс.html

2. При загрузкеページ появится блок:
   "📊 Выберите модель счетчика (как при разборе маски):"
   
   Это выпадающий список со всеми доступными моделями.

3. Выберите модель, которая соответствует вашим данным
   Например: "Энергомера CE208 (Энергомера)"

4. Вставьте hex-сообщение в поле ввода

5. Нажмите кнопку "🔍 Разобрать (8 байт)" или "🔍 Разобрать (4 байта)"

---

## ШАГ 2: ПРОВЕРКА В КОНСОЛИ

После нажатия кнопки разбора откройте F12 → Console

Вы должны увидеть:

```
✅ Зарегистрирована модель: energomera-208 - Энергомера CE208
✅ Зарегистрирована модель: mercury-204-208-19 - Меркурий 204/208X v19
...
🏭 ===== ИТОГИ ИНИЦИАЛИЗАЦИИ МОДЕЛЕЙ =====
✅ Зарегистрировано моделей: 28
⚠️  Не найдено переменных: 0
📦 Доступные модели: ["energomera-208", "mercury-204-208-19", ...]
```

Если все 28 моделей зарегистрированы - интеграция работает!

---

```

```

---

## РЕЗУЛЬТАТ НА ЭКРАНЕ

После успешного разбора должна появиться:

📊 ТАБЛИЦА "Маппинг объектов" с колонками:
- Позиция
- ID объекта
- Название (например: "⚡ A+ T0")
- Группа (например: "Активная энергия (потребление)")
- OBIS код
- Значение в кВт

И СВОДКА по типам энергии:
- A+ - Активная энергия (потребление) - Итого: XXX кВт
- A- - Активная энергия (отдача) - Итого: XXX кВт
- R+ - Реактивная емкостная - Итого: XXX кВт
- R- - Реактивная индуктивная - Итого: XXX кВт

## ТЕСТ С ПРИМЕРОМ

Скопируйте это hex-сообщение:
```
44C815010180300601CE000058320000000000000000000000000000000000
```

1. Вставьте в поле ввода
2. Выберите модель "Энергомера CE208"
3. Нажмите "Разобрать (8 байт)"
4. ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:
   - Таблица с 10 объектами (A+, A-, R+, R-)
   - Маска правильно декодируется в объекты
   - Значения отображаются в кВт

## ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### Проблема: Dropdown пуст
❌ Модели не загружаются
Решение:
  - F12 → Network → проверьте загружаются ли config files (*.js)
  - F12 → Console → вверху должны быть логи "✅ Зарегистрирована модель"
  - Если пусто - проверьте что init-models.js подключен в HTML

### Проблема: Dropdown есть, но без моделей
❌ Модели не регистрируются
Решение:
  - F12 → Console → введите: Object.keys(window.AVAILABLE_MODELS)
  - Должно вывести массив моделей
  - Если пусто - значит config файлы не загружаются

### Проблема: Модель выбрана, но таблица не появляется
❌ Маппинг не работает
Решение:
  - F12 → Console → введите: typeof decodeMask
  - Должно вывести "function"
  - Если "undefined" - mask-utils.js не загрузился

### Проблема: В console видны ошибки
❌ JavaScript ошибки
Решение:
  - Скопируйте текст ошибки
  - Проверьте что все файлы на месте:
    - mask-utils.js 
    - init-models.js
    - configs/.../*.js

---

Файлы которые должны быть:
✅ mask-utils.js (функции для декодирования масок)
✅ init-models.js (инициализация dropdown'а)
✅ configs/*.js (28 конфигов моделей)
✅ суточные сподэс.html (обновлено с dropdown'ом)
