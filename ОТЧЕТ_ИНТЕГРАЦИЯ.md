## АРХИТЕКТУРА РЕШЕНИЯ:

```
Загрузка страницы
↓
1. Загружаются все конфиг-файлы (28 .js файлов)
2. Загружается mask-utils.js (функции маппинга)
3. Загружается init-models.js
   ├─ Ждет DOMContentLoaded
   ├─ Перебирает список configVariables
   ├─ Проверяет window[varName] на наличие
   ├─ Регистрирует в window.AVAILABLE_MODELS
   ├─ Добавляет опции в dropdown #modelSelector
   └─ Логирует результаты в Console

Пользователь:
1. Выбирает модель из dropdown
2. Вставляет hex-сообщение
3. Нажимает "Разобрать (8 байт)"
   ├─ parseMessage() получает выбранную модель
   ├─ displayResult() получает selectedModel
   ├─ Вызывает decodeMask(mask, selectedModel)
   ├─ Вызывает mapDataIndicesToObjects()
   ├─ Вызывает generateObjectMappingTable()
   └─ Выводит таблицу с названиями объектов
```

## ПРОВЕРКА РАБОТОСПОСОБНОСТИ:

1. Откройте F12 → Console
2. После загрузки должны быть логи:
   ```
   ✅ Зарегистрирована модель: energomera-208 - Энергомера CE208
   ✅ Зарегистрирована модель: mercury-204-208-19 - Меркурий 204/208X v19
   ...
   🏭 ===== ИТОГИ ИНИЦИАЛИЗАЦИИ МОДЕЛЕЙ =====
   ✅ Зарегистрировано моделей: 28
   ⚠️  Не найдено переменных: 0
   ```

3. На странице должен быть dropdown с моделями

4. Тестовое сообщение:
   ```
   44C815010180300601CE000058320000000000000000000000000000000000
   ```
   
5. После разбора должна появиться таблица с названиями объектов
